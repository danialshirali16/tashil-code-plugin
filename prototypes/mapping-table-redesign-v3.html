Mapping — third pass

Honest read on why the built version still feels wrong, then three ways out. Real Button data throughout.

What I got wrong in the two-pane board
  • Three regions to coordinate. Choose a prop on the right, look left for its value, then down to the detail panel. In a narrow plugin that is a lot of eye travel for one decision.
  • The left column is mostly dead. It is scoped to the focused prop, so with a text prop selected nearly every row is disabled. A list where most rows are greyed reads as broken no matter what the hint says.
  • I conflated two jobs. "Which Figma value feeds this prop?" needs only the compatible values. "What is unused in Figma?" is an audit question you ask once — it does not deserve half the screen permanently.
  • Height. Board + detail + preview stacks well past one screen before any real work happens.
Option 1 — recommended

Inline — decide where you are looking

One list of code props. Expanding a row reveals the choice in place: the named source kinds, and for “From Figma” only the values that can actually feed that prop — so nothing is greyed out and there is no second column to consult. The audit question gets a single collapsed line at the top instead of a permanent pane.

Option 2

One control, search to connect

Every prop keeps a single control. Clicking it opens a picker grouped by kind with a filter box — type st and you get State. Nothing is ever greyed, the row height never changes, and 27 props behave exactly like 8. Fastest once learned, least discoverable at first.

My pick: Option 1. The decision happens where your eye already is, and it removes the fault that actually broke the last build — a column of greyed-out rows — by showing only what can feed the prop you are on. The Figma-coverage line keeps the one genuinely useful thing the board gave you (“what is unused”) at a cost of one row instead of half the panel.

Option 2 is the best answer if InfoModal-sized components are the norm; its row height never changes. Option 3 is the smallest step from today if you would rather keep the board.
