Which Figma value?

My pick: A. It is one decision instead of two, nothing is ever greyed out, and each option states what it means — so the control teaches itself without a paragraph underneath. It also scales honestly: if a component offers eight compatible Figma values they are all simply listed, whereas C would still make you open a second control to see them.

Pick B instead if you expect long prop lists and want every expanded row to stay short. All three drop the four cramped buttons.
